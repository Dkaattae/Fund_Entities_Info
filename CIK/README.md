# New CIK lookup tool

For any firm name you find, use the SEC CIK Lookup.
https://www.sec.gov/edgar/searchedgar/cik.htm

If the CIK exists but there are NO filings: This is a "Pending" lead. They have their "passport" (CIK) but haven't started "traveling" (filing) yet.

If the only filing is an "Auditor Appointment" (17a-5): They just hired someone. Check if it's a competitor or a firm you can sub-contract for.
